# 📖 Overview

**Student Management System** is a terminal-based application developed using **Bash Shell scripting** as part of an academic project.

The system provides an efficient way to manage student records, teacher authentication, subject information, grades, and CGPA calculations using file-based storage. It demonstrates practical Linux system programming concepts, shell scripting, automation, and file handling through an interactive command-line interface.

---

# ✨ Features

### 👨‍🏫 Teacher Module

- Teacher Login
- Add New Teachers
- Manage Student Records

### 👨‍🎓 Student Module

- Student Login
- View Academic Record
- View Grades & CGPA

### 📚 Academic Management

- Add Students
- Add Subjects
- Assign Marks
- Automatic Grade Calculation
- Automatic CGPA Calculation

### 💾 File Management

- File-Based Database
- Secure Authentication
- Record Searching
- Record Updating

# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/USERNAME/student-management-system-bash.git
```

### Navigate

```bash
cd student-management-system-bash
```

### Give Execute Permission

```bash
chmod +x code.sh
```

### Run

```bash
./code.sh
```
